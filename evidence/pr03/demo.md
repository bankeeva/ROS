# ПР03. Демо

## Роли компонентов

- `rclpy.init()` — иинициализирует ROS, создаёт общий контекст для работы ноды.
- `rclpy.spin(node)` — запускает цикл обработки событий. Без него нода просто завершит работу, не успев ничего сделать.
- `callback` — короткая функция-обработчик. В нашем коде подписка просто сохраняет последнюю позу в переменную, а callback таймера читает эту переменную и публикует команду.
- `Ctrl+C` — прерывает работу `spin()`. Мы ловим это исключение (`KeyboardInterrupt`), чтобы корректно вызвать `destroy_node()` и освободить ресурсы.

## Почему после остановки ноды turtlesim не останавливается мгновенно

Симулятор turtlesim просто продолжает выполнять последнюю полученную команду скорости. Когда мы делаем Ctrl+C, наша нода завершается и перестает слать команды, но явной команды на остановку (нулевой `Twist`) отправлено не было. Поэтому черепаха продолжает двигаться. Чтобы она остановилась сразу, нужно явно опубликовать нулевую команду перед уничтожением ноды.

## Воспроизведение дефекта

1. **Без remap:** `ros2 run patrol patrol`
   - Нода публикует в относительный топик `cmd_vel`.
   - `ros2 topic info /turtle1/cmd_vel --verbose` показывает 0 publishers. Черепаха стоит.
2. **С remap:** `ros2 run patrol patrol --ros-args -r cmd_vel:=/turtle1/cmd_vel`
   - Имя топика исправлено на полное.
   - `ros2 topic info /turtle1/cmd_vel --verbose` показывает 1 publisher. Черепаха едет.
